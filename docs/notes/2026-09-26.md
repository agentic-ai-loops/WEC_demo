# Task 1: Build the site

- First rename `intelliw.design` to `intelliw.render`
- Refer to @docs/design/04-design.md on the template rendering design.

All services and types go to `intelliw.render` module.

Then create a CLI tool:

```
uv run render
```

with:

```python
workspace: str = typer.Argument(...)
includeHidden: bool = typer.Option(False, '--include-hidden')
version: int|None = typer.Option(None, '--version')
snapshot: str|None = typer.Option(None, '--snapshot')
design: str = typer.Option(..., '--design', '--template')
dryrun: boolean = typer.Option(False, '--dryrun')
```

It will render #businessdata (either active, or version/snapshot) using the design given by `--design`.
It will perform a list of rule checking (refer to @docs/design/04-design.md).

If `--dryrun`, then do not save anything, but it will run all the gql and render the templates.
