# business data terminal

This is a design for inspection of business data.

- frontpage has references to all business entities but with some details omitted.
- each business entity has its own sub-page.
- all #businessdata are discoverable by navigating from the frontpage.

**styling**
- only use monospace
- all black and white and gray
- black/gray text on white/light-gray background
- simulate a terminal experience
- use python rich style panel containers to render entities
- use simple sections

This is a system debug oriented design with a retro look.
