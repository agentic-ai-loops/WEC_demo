# A professional design

- This is a design based on bootstrap styling.  Also use an icons library.
- The design is a professional looking e-commerce site for an optometrist clinic.
- Use javascript to create interactive and web embedding

Use layout templates to have a consistent overall layout with reactive navigational menu to jump to top level pages.
Use industry standard and beautiful layout for a professional look that is representative of a polished medical clinic.
Use font and consistent color scheme to achieve a high contrast look.
Use CSS to create layout, effects and text effects.  But do not be overly flashy.

# Pages

Include the following sections:
